# Assumptions & SME Answers

A running log of assumptions made and SME answers given during AFK development loops. Every entry here represents a decision made without direct human input. Review this file when returning from an AFK session before merging any SME branch.

## How to read this file

- `ASSUMED` — agent made a low-blast-radius assumption and continued; verify before shipping
- `SME-ANSWERED` — SME agent provided a domain knowledge answer; check confidence level
- `BLOCKED` — loop stopped; human input required before work can continue
