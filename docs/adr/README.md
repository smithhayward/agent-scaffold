# Architecture Decision Records

Lightweight records of significant decisions: what was decided, why, and what was rejected.

## Format

Each ADR is a single markdown file named `NNN-short-title.md`.

```
# ADR-NNN: Title

## Status
Proposed | Accepted | Superseded by ADR-NNN

## Context
What situation forced a decision.

## Decision
What was decided.

## Alternatives considered
What else was on the table and why it was rejected.

## Consequences
What becomes easier, harder, or constrained as a result.
```
