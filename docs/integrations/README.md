# Integrations

Per-integration setup, configuration, and behavioral notes. One file per external system the product connects to.

## Naming convention

`<system-name>.md` — e.g., `aws-iot-core.md`, `home-assistant.md`, `influxdb.md`

## What goes here

- Connection and auth setup
- Topic/channel mapping conventions
- Known quirks or limitations of the integration
- How to test it locally (broker simulators, stubs)
